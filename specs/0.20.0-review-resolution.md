## Behavioral limits

Watch completeness is deliberately conservative. A played movie that cannot be mapped makes watch-dependent maintenance decisions unknown, including on mixed media-server catalogs containing unmanaged movies. This prevents missing or ambiguous identity from becoming evidence that a managed title was never watched. Observations remain stored for later mapping; unrelated non-watch maintenance facts remain usable.

Rename recovery uses a registered system setting introduced by paired schema migration 0226. The journal is part of the existing settings backup export. Startup retries it; registry mutations also retry before allowing a previous label to be reused.

Request approval status, claims and resolution events commit together. Title creation still precedes that transaction: a claim-write failure can leave the created title while the request remains pending and retryable, with no approval event committed.

E2E work remains excluded. Full workspace Nextest and Clippy are deferred to the completed integration checkpoint. PostgreSQL execution is unavailable locally; paired PostgreSQL migration and SQL transaction paths are present, with SQLite regression coverage. No release or application-instance operation was performed.
