## Implemented scope

- Hash backfill runs independently of acquisition, serializes concurrent starts,
  retains its execution guard while blocking reads finish, checkpoints completed
  files, and supports cancellation and restart. Panics finalize the job as failed.
- Interactive acquisition derives title-scoped targets and supports cancellation
  while waiting for the title lock and between proposals. Pack-first ordering is
  preserved. Cancellation does not preempt an already executing submission.
- Rust startup plugin repair validates identity, origin, SDK compatibility,
  descriptors, and component initialization before atomic replacement. It uses
  trusted bundled replacements or the existing verified catalog installation
  pipeline. Original configuration, installation identity, origin and enabled
  preference survive. Unrepairable installations retain their artifacts and expose
  a provider blocker; startup no longer deletes legacy external installations.
- Schema migration 0225 supplies a durable per-target compatibility journal on
  SQLite and PostgreSQL. It is included in backup exports. Restart retries and
  failed writes retain original journal evidence.
- Rust proxy startup validation retains configurations, encrypted credentials and
  assignments. Runtime routing rejects unusable assignments, including blank IDs.
  A proxy read failure blocks its assigned indexers without aborting unrelated
  indexer searches. Invalid supported-width timeout values remain editable.
- Move imports recover after catalog persistence fails, verifying an uncataloged
  destination before claiming it and removing the source. Conflicting content
  requires manual reconciliation and preserves both files. Existing copy-mode
  duplicate handling is preserved.
- Root upgrade tests cover older/current baselines, multiple roots and library
  assignments, atomic rollback, retry and idempotence.
- Request-rule Rust tests cover hidden experimental UI with armed rules, gate read
  failure, trace persistence failure and bounded evaluation. Armed evaluation
  errors hold the request; hiding the UI does not disarm enforcement.
