# Russian names in series-pack members

For a series download submitted by Scryer with a verified, exact episode set
and exactly one declared season, member filenames can use a deterministic Latin
romanization of the Russian catalog name (or a declared alias) without adding
another alias. For example,
`ИИскра` can agree with `IIskra.S01E09.2026.WEB-DL.1080p-Group.mkv`.

This is not fuzzy title search. The full name must agree, including word
boundaries and repeated letters. The member must carry the matching known year,
an explicit season and episode, and belong to the submission's exact set.
Different titles, extra name words, mixed scripts, contradictory season folders,
season-only filenames, duplicate mappings and episodes outside the saved set
remain held. Normal quality, replacement and transfer policies still apply.

The romanization is deliberately conservative: `ж → zh`, `х → kh`, `ц → ts`,
`ч → ch`, `ш → sh`, `щ → shch`, `ё → yo`, `й/ы → y`, `ю → yu`, `я → ya`;
`ъ/ь` are omitted. Other Russian letters use their direct Latin spelling.
Alternative spellings, other Cyrillic alphabets, unknown years and downloads
without a verified exact episode set still require the existing explicit alias
or manual-selection workflow. No aliases or existing import bindings are
rewritten automatically.
